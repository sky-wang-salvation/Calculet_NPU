## 2. 下载方式与空间边界

本地磁盘约 50 GB 可用是本轮约束。抓取器配置模型数据预算 256 MiB，没有调用不受限的整模型 snapshot 下载。

源参数位于 `transformer/diffusion_pytorch_model-00006-of-00006.safetensors`，该分片声明大小 3,799,304,904 字节。已保存的抓取记录包含三次经过长度校验的 HTTP 206 范围响应：

| 请求 | 范围或内容 | 接受的响应体字节数 |
| --- | --- | ---: |
| 配置与索引 | README、Transformer config、权重 index | 125,236 |
| safetensors 前缀 | 字节 `0–7` | 8 |
| safetensors header | 字节 `8–13383` | 13,376 |
| 完整 bias 和投影权重 | 字节 `3760384328–3761965383` | 1,581,056 |
| 记录合计 | 成功抓取调用接受的最终响应体 | **1,719,676** |

约 1.64 MiB 是上述调用的**最终响应体计数**，不是所有网络流量统计；不包括较早的元数据探索、HTTP 头和中间重定向正文。完整模型和完整分片没有保存到本地，也没有再次下载用于归档。

初版下载保护审查发现重定向正文可能被标准库自动读取，随后已修复并增加回归测试；修复后只做了离线回归，没有为证明新版本而重新下载参数。最终代码还会在服务端忽略 Range、返回 200、范围或大小不符时拒绝读取大正文。

来源文件清单提供了整个分片的声明 SHA-256，但由于未下载整片，**不能声称已独立验证整个分片哈希**。实际取得的小配置、header、参数范围及导出 W/b 的哈希分别保留在 [source_manifest.json](ref/schedule_03_20261116/source_manifest.json)。ModelScope 镜像上传者身份没有独立认证；模型卡声明 OpenMDW1.1，不据此扩大许可或再分发范围。

## 3. 本地 Linux CPU 参考已生成
